# dsh-workbuddy-switch

将 **WorkBuddy（腾讯 CodeBuddy）账号**接入 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的模型提供方插件。本项目为非官方实现，声明见「法律与免责」。

```sh
dsh plugin --profile <profile> add dsh-workbuddy-switch@0.1.0
# 安装后重启 profile（桌面端为重启 DSH Desktop）；模型选择器出现 WorkBuddy 分组即表示挂载成功
```

## 能力

| 能力 | 说明 |
|---|---|
| 模型接入 | 模型选择器提供 **WorkBuddy** 分组，支持流式输出、思考内容与工具调用 |
| 多账号 | 支持浏览器设备授权与令牌导入；账号池按积分最多优先选择账号，失败后切换至下一账号；设置页可指定之后新建的会话使用哪个账号；对话底部 pill 与设置页展示额度，并按日自动签到 |
| 会话锁 | 同一会话固定使用同一账号以维持前缀缓存命中；该账号达到上限时中止请求并说明原因，不静默切换账号。在设置页切换账号只影响之后新建的会话，已开始的会话保持原账号，重启后按其上次使用的账号恢复 |
| 图片输入 | 视觉模型接受粘贴或拖拽的图片与 `read_image` 结果，按体积预算压缩后发送 |
| CN / Global | CN 与 Global 两个域的账号可同时登录，互不影响 |

请求仅使用所选模型：全部账号对该模型均不可用时，以 `MODEL_UNAVAILABLE` 中止并提示更换模型。

## 快速开始

1. **登录**：向 agent 提出登录请求，由其调用 `workbuddy_login`（`start` → `finish`），在浏览器完成授权。多账号重复该流程。
2. **选择模型**：在模型选择器的 **WorkBuddy** 分组下选择模型。模型目录以账号实际可用的模型为准，包含单价与活动标记。
3. **查询状态**：`workbuddy_account action="list"` 列出账号、过期时间、冷却状态与积分余额；`action="quota"` 强制刷新额度快照。

无浏览器环境使用令牌导入：`workbuddy_login {action:"token", tokenFile:"…"}`，支持 WorkBuddy auth JSON 与裸 token 文本。裸 token 文件须位于 `$DSH_HOME`、`~/.codebuddy`、`~/.workbuddy`、`%APPDATA%`、临时目录或当前工作目录下，内容须为单行令牌；不满足该形态的文件不会作为令牌读取。

## 账号与额度

- **对话底部 pill**：显示形如 `风清 · 剩 1074 · 本会话 3.2`，依次为本会话锁定的账号、剩余积分、本会话累计消耗，每 60 秒刷新。数据只读，响应不含任何令牌。
- **设置 → WorkBuddy**：账号表包含签到、额度重置时间、积分余额与删除操作，并提供刷新、立即签到、添加账号三个页级动作。切换在表内完成，「切换」列每行给出此刻的状态或可做的动作：固定住的那行显示「当前」，鼠标移上去（或键盘聚焦）变成「取消」，点它回到不固定状态；未固定时账号池按积分会挑的那一行显示「当前（自动）」，悬停变成「切换」，点它把这个账号钉住；其它可服务的行在同样条件下浮出「切换」，点一下即改为该账号——被选的账号变「当前」，上一个变「最近」，这个记录会保存，刷新页面后仍然在。冷却中的账号与被固定但不可用的那行不给按钮。切换只影响之后新建的会话，已开始的会话保持原账号。
- **headless / CLI 组合**：无页面，pill 与设置页均不显示；两个模型工具仍可使用。

## 已知限制

- 模型单价与活动标记仅用于展示；实际扣费由上游按「模型 × 时段 × token」结算。
- 图片能力仅覆盖输入。工具结果中的图片会以紧随其后的 user 消息重放，历史越长占用越大，由图片预算与省略机制兜底。
- 冷却粒度：额度耗尽以 `QUOTA` 冷却至次日 04:00（UTC+8）；`6004` / `6021` 仅冷却「该账号 + 该模型」。
- 所选输出 token 上限可能被上游静默下调。
- 自动签到按 UTC+8 自然日计算；更换 `DSH_HOME` 会丢失当日签到缓存。
- 上游以 `11128`（渠道检查）拒绝系统提示词时无本地绕法：插件按 harness 装配的结果原样转发，不提供模板、替换或改写开关；能动的只有换模型。
